# Components

Every component is plain HTML with `.hd-*` classes from `css/components.css`. Icons are inline SVGs (copy from `icons/svg/` or use the sprite). See each one rendered in `examples/element-board.html`; the **E-number** below is its card on the board.

Naming is BEM-style: `.hd-block`, `.hd-block__part`, `.hd-block--variant`.

---

## Atoms

### Icon well · `.hd-well`
Round pastel background holding an icon in the matching ink.
Variants: `--aqua --sun --peach --mint --rose --lav --sky --white --grad --navy --ghost`, `--sq` (rounded square). Size with `--well:52px`.
```html
<span class="hd-well hd-well--aqua"><svg class="hd-icon" width="54%" height="54%" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2.2" stroke-linecap="round" stroke-linejoin="round"><!-- icons/svg/lab.svg --></svg></span>
```

### Button · `.hd-btn`
`--primary` (gradient, glow: one per view), `--navy`, `--secondary` (white, outlined), `--ghost` (tint), `--sm`.
```html
<button class="hd-btn hd-btn--primary">Book a test</button>
```

### Chip · `.hd-chip`
Pill with a well and a label: touchpoints, agents, filters. `--solid` = active (gradient, white text), `--ghost`, `--text`.
```html
<span class="hd-chip"><span class="hd-well hd-well--sun">…</span>Collection agent</span>
```

### Tag · `.hd-tag`
Small status pill. `--sky --aqua --sun --mint --rose --lav --navy --white --grad`. Use mint for "Live", sun for "Pending", rose for problems.

### Badge · `.hd-badge` / unread · `.hd-unread`
Red count bubble; "3 unread messages" pill.

### Toggle · `.hd-toggle` (`.is-on`), progress · `.hd-progress` (`--thin --mint --amber --rose`, set `--p:62%` on `.hd-progress__fill`)

### Placeholder value · `.hd-ph`
Yellow highlight for a figure you don't have yet: `<span class="hd-ph">[X%]</span>`. Numbers are illustrative and set per use case (see `content.md`).

### Slot · `.hd-slot`
Dashed "PLACEHOLDER" box for a logo or screen still to be supplied.

## Type styles (E-18)

| Class | Use |
|---|---|
| `.hd-kicker` | Caps label above a headline (19px, 700, 3px tracking, blue) |
| `.hd-headline` | Headline. Wrap the key phrase in `<em>` to colour it blue (or the partner ink) |
| `.hd-headline--xl` | End card / title frame |
| `.hd-subline` | One supporting line under a headline |
| `.hd-statline` (`__num`, `__txt`) | Big number + short explanation side by side |
| `.hd-caption` | Small grey caption, sources, footnotes |
| `.hd-lower` | Lower-third callout with a well |

In scenes, wrap each word in `<span class="w">` so headlines can rise word by word (`HD.words`).

## Scene building blocks (`css/scene.css`)

| Class | Use |
|---|---|
| `.hd-viewport > .hd-stage` | Fixed 1920×1080 stage scaled to the window by `HD.player` |
| `.hd-world` | Origin at stage centre; position elements with `translate(x,y)` |
| `.hd-shell` + `__bg __orb __clip __content` | The shape-morph element (`motion.md`) |
| `.hd-player` | Play/pause + seek bar (added by `HD.player`, not part of the frame) |

## Adding a component

1. Build it on the element board first (`source/gen/s*.py`), using tokens only.
2. Give it an E-number card with: name, scenes used in, motion notes.
3. Add its CSS to `css/components.css` and a row here.
4. Bump the minor version in `CHANGELOG.md`.
